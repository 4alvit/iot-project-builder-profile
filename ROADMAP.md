# Roadmap

This roadmap covers 16 October 2026 through at least 16 October 2027.

- Preserve the credential-free heuristic generation mode and extend source-analyzer regression cases.
- Expand measured statement and branch coverage across application and publishing/release helpers.
- Independently verify the optional Anthropic transport before extending the strict TLS claim to it.
- Maintain locked dependency updates and native CPython TLS compatibility tests.

Discuss proposed changes through public issues and pull requests. Plans are not delivered features or promised dates. A backup maintainer and a tested access-recovery arrangement remain absent.

## Non-goals

Do not execute scanned repository content, infer private individual attributes, automatically publish profiles without review, or treat model-generated assessments as verified facts.
